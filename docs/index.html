Hardware Installation Guide • Traqr Firmware

Step 1

Install Firmware

Download the latest .ptf firmware for your device (Mini, Original, or Plus) from GitHub Releases. Copy the file to the /Firmware/ folder on your MicroSD card. In Tracker Settings, choose Firmware Update.

Step 2

Load Presets

Extract the downloaded presets into /Instruments/Synths/JUNO/ and /Instruments/Synths/TEAR/ on your MicroSD card.

Step 3

Play & Performance Mode

In Instrument Parameters, select the engine or load any .patch preset. Switch to the dedicated Synth Performance screen (Shift+Perform) featuring an 8-macro layout (Macros 1–6 + Delay + Reverb) optimised for tactile control with the Novation Circuit Tracks!
