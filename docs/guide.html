Getting Started

1. Firmware Installation & SD Card Setup

Download the latest Traqr release bundle from GitHub Releases and place the files on your microSD card as shown below: 

SD Card Root/
├── Firmware/
│   └── TrackerMini_NL_1.0.26.ptf   (or TrackerPlus_NL_*.ptf / PolyendTracker_NL_*.ptf)
├── Patches/
│   ├── JULYO/                      (unzipped contents of JULYO_Patches.zip)
│   └── TEAR/                       (unzipped contents of TEAR_Patches.zip)
└── Effects/
    └── *.ptfx                      (optional: unzipped PolyendTracker_CE_Effects.zip)
  1. Back up any important projects from your SD card before flashing firmware.
  2. Insert the microSD card into your Tracker and navigate to Config → Firmware → Firmware update.
  3. Select the Traqr .ptf file for your model (Tracker Mini, Tracker+, or Original Tracker) and confirm.
Note for Original Polyend Tracker (MK66): Traqr's wavetable improvements, Master Stereo Chorus send, and Sample Editor .ptfx plugins run across all hardware models. Internal polyphonic synth engines (JULYO, TEAR, and Synth Performance) require the Tracker Mini or Tracker+ IMX synth platform.
Polyphonic Engines

2. JULYO & TEAR Custom Synth Engines

Traqr adds two custom polyphonic synth engines alongside Polyend's stock engines (ACD, FAT, VAP, WTFM, PERC, DIRT, CHIP).

Selecting an Engine & Loading Presets on Hardware

  1. Switch to any Synth slot (Synth 1, Synth 2, or Synth 3).
  2. Open Instrument Parameters to enter the Synth Editor.
  3. Turn the encoder / adjust the engine selector to pick JULYO or TEAR, or open the Patch Browser to load any .patch file placed in /Patches/JULYO/ or /Patches/TEAR/.
  4. Use the 6 editor page buttons at the bottom of the screen to sculpt every parameter, then save or tweak the 6 Macros for live automation.

Designing Patches in Your Browser

Both JULYO Web Synth and TEAR Web Synth run the exact same C++20 DSP code compiled to WebAssembly:

  • Play notes with your computer keyboard, mouse, or a connected USB MIDI controller.
  • Audition all built-in factory presets (40 in JULYO, 18 in TEAR), configure custom Macro 1–6 parameter bindings and ranges, then export either a single .patch file or a full preset .zip directly to your SD card's /Patches/ folder.

JULYO — 60/106-Style Vintage DCO Poly

Inspired by classic 1980s Japanese 60/106 Roman-goddess analog polysynths. 6 pages: DCO, Filter, F-Env, A-Env, LFO, Chorus.

  • DCO: Saw Level, Pulse Level, Pulse Width, PWM Depth/Source, Sub Level/Sub Octave, Noise, Voice Drift.
  • Filter: Non-resonant HPF + 4-pole resonant LPF (Cutoff, Resonance, Env Amount, LFO Amount, Key Track, OTA Drive).
  • BBD Chorus: Dedicated stereo Chorus (Off, I, II, I+II) built into the synth engine.
  • Default Macros 1–6: Cutoff, Resonance, Env Mod, Sub / Bass, PWM Depth, Release.

TEAR — Phase-Tearing Sync

6 pages: Osc, Mod, Filter, Env 1, Amp, Voice.

  • Oscillator: 5 Sync Modes (Hard Tear, Soft Reverse, Windowed Formant, Dual SuperTear, Ring Shred), Sync Ratio, Shape Morph, and Sub Osc.
  • Sync Modulation: Dedicated Sync Decay / Sync Depth envelope and Sync LFO Rate / Depth.
  • Filter & Drive: Selectable Filter Model, Drive, 5 Saturation circuits, and Glide Mode/Time.
  • Default Macros 1–6: Tear Pitch, Sync Env, Sync LFO, Cutoff, Drive, Shape Morph.
Live Control & MIDI

3. Synth Performance Mode & Circuit Tracks MIDI

Synth Performance puts all 3 active Synth parts on one live control surface styled around an 8-column layout: Macros 1–6 + Delay Send + Reverb Send. Every row shows the active patch, MIDI channel, voice count, Volume (dB), Pan, live stereo L/R RMS meters, and updates in real time when Pattern FX automate macros or sends.

How to Open Synth Performance

Press Menu to open the module grid and choose Synth Performance (located in the bottom-right / Game module slot).

Synth Performance On-Device Controls

Screen Buttons 1–8 Select Macro 1–6, Delay, or Reverb Pressing the already-selected column button cycles through Synth 1 → 2 → 3.
Left / Right Move column selection Steps horizontally across columns 1–8.
Up / Down Switch Synth row (1–3) Hold Shift + Up/Down to nudge the active parameter by ±1.

Multitimbral MIDI Routing & Novation Circuit Tracks

You can drive all 3 Synth parts simultaneously from an external sequencer or groovebox such as the Novation Circuit Tracks:

  1. Open Config → MIDI.
  2. Make sure Notes in and CC in are enabled for your USB or MIDI IN port.
  3. Assign independent MIDI channels to Synth 1 MIDI ch, Synth 2 MIDI ch, and Synth 3 MIDI ch (for example, channels 1, 2, and 3, or Circuit Tracks MIDI track channels).

Sample & Wavetable Synthesis

4. Enhanced Wavetable Engine: Sub-Osc, Warp & Modulation

Traqr upgrades Sample Playback's Wavetable mode with a phase-locked sub-oscillator, three oscillator warp modes, independent Wavetable Warp modulation, 32-sample de-clicked window stepping, a 32-sample note-onset declicker, and fixed single-cycle seam wrapping in ITCM RAM — while remaining 100% compatible with official Polyend projects.

Using Sub-Oscillator & Warp in Sample Playback

  1. Select a sample-based instrument and open Sample Playback.
  2. Press Play Mode (Screen Button 7) and pick Wavetable.
  3. Set starting Position (Button 2) and single-cycle Window size (Button 3).
  4. Press Sub Wave (Button 4) to pick Off, Sine, Tri, or Square. Turning it on from Off automatically initializes Sub Level (Button 5) to 20%; dial 0%–100% to taste.
  5. Press Warp (Button 6) to choose a wave/phase shaper and turn up the Warp amount (0%–100%; enabling a Warp mode defaults amount to 50%):
Wavetable Sub-Oscillator & Warp Controls
Feature Display / Options Sonic Behavior
Sub Wave & Level Off, Sine, Tri, Square • 0–100% Phase-locked sub-oscillator tracked to the fundamental cycle for solid low-end weight without phase drift.
Warp: Asymmetric Asy 0–100% Bends phase symmetry inside each wavetable cycle (PWM-like timbre shift on any wavetable).
Warp: Sync Snc 0–100% Accelerates readout phase inside the cycle and hard-resets at the period boundary for tearing sync harmonics.
Warp: Fold Fld 0–100% Applies wavefolder gain and reflection for rich metallic overtones and gritty harmonic saturation.

Simultaneous Modulation of Wavetable Position & Warp

Because Wavetable Warp has its own dedicated modulation slot alongside Wavetable Position, you can animate both at the same time:

  1. Press Instrument Parameters twice to open Instrument Automation (2/2).
  2. Select Destination Wavetable Position and set Type to Envelope, LFO, WT Env, or WT LFO to scan frames over time.
  3. Still on Destination column 1, select Wavetable Warp and assign a separate Envelope, LFO, WT Env, or WT LFO.
  4. Modulation adds cleanly onto your instrument's base Warp percentage (clamped 0%–100%), updating live as notes play.
Want custom modulation shapes & Pattern FX? See the companion Wavetable Envelopes (WT Env), LFOs (WT LFO) & Step FX (w / y) Guide for dual-axis Warp X/Y curves and user wavetable loading.
Master Send Effects

5. Master Stereo Chorus Send Effect

Traqr adds a warm, dual-modulated BBD-style Master Stereo Chorus wired as a global send effect alongside Delay and Reverb.

Signal Routing Scope: Sample-based instruments, Wavetable instruments, and Line In route into the Master Chorus send. Polyphonic Synth tracks (S1–S3) are intentionally excluded — use JULYO's built-in stereo BBD Chorus or TEAR's internal modulation instead.

Step 1: Send an Instrument to Chorus

  1. Select a sample or wavetable instrument and open Instrument Parameters → Effects (1/2).
  2. Press More to open the secondary Effects page.
  3. Turn up Chorus send (Screen Button 6) from 0% to 100%.

Step 2: Shape Tone in Master 1/3 → Master Chorus

Open Master 1/3 and press Chorus (Screen Button 8, replacing the standalone Space slot). Inside the Master Chorus screen:

Master Chorus Screen Parameters
Parameter Range / Control Function
Rate (Btn 1) 0.10 Hz – 5.00 Hz LFO modulation speed across the stereo delay lines.
Depth (Btn 2) 0% – 100% Pitch and delay modulation intensity.
Width (Btn 3) 0% – 100% Stereo L/R phase offset and image wideness of the wet Chorus signal.
Space (Btn 4) 0 – 8 Master stereo widening boost (moved inside the Chorus menu to free Master 1/3).
Line in (Btn 5) 0% – 100% + Shift Mute Controls how much external Line In audio feeds Chorus. Hold Shift + press Line in to Mute/Unmute.
Back (Btn 8) Button press Returns directly to Master 1/3.

Step 3: Mix the Chorus Return in Global Mixer 3/3

  1. Cycle to Global Mixer 3/3 (the Sends / Returns mixer page in Master mode).
  2. Use the dedicated Chorus channel strip to trim the stereo return fader, watch real-time L/R RMS meters, or Mute / Solo the Chorus return alongside Delay and Reverb.
